# MAICON 2026 전술 시뮬레이터

[게임 바로 실행하기](https://kakaka79da.github.io/maicon2026-tactics-simulator/)

링크를 클릭하면 별도의 다운로드나 설치 없이 웹 브라우저에서 게임 화면이 열립니다. 화면의 **시작** 버튼을 누르면 가상 경기가 진행됩니다.

## 제작 목적

대회 전에 예상 시나리오를 가상으로 체험하고, 다양한 상황과 전략을 비교하며 팀의 대응 방법을 고민하고 토의하기 위한 사전 학습 도구입니다. 조건을 바꾸어 경기를 살펴보면서 어떤 선택이 유리할지 생각하고, 실제 준비 과정에서 확인할 질문과 전략 아이디어를 찾아보세요.

## 실제 대회와의 차이

**이 시뮬레이터는 실제 대회와 다를 수 있습니다.** 공식 대회 운영 시스템이 아니며, 규칙·경기장·장비 성능·상대 전략과 경기 상황을 단순화하거나 가정한 부분이 있습니다. 경기 결과와 승률은 이 가정 안에서 계산된 참고 자료이며, 실제 대회 결과를 예측하거나 보장하지 않습니다.

실제 참가 준비와 의사결정에는 주최 측의 최신 공식 규정과 안내, 실제 장비 시험 결과를 우선 적용하세요.

## 사용 방법

1. 위 실행 링크를 열고 **시작**을 누릅니다.
2. **×1·×2·×5·×20**으로 진행 속도를 조절하고, 필요한 순간에는 **일시정지**하여 상황을 살펴봅니다.
3. **형세 설정**에서 조건을 바꾼 뒤 **이 설정으로 새 경기**를 눌러 전략에 따른 차이를 비교합니다.
4. **승률 실험**으로 여러 경기의 경향을 살펴보고, **규칙과 가정**을 함께 읽으며 팀원들과 대응 전략을 토의합니다.

## 배포 안내

GitHub Pages_깃허브 페이지스(저장소의 파일을 웹사이트로 제공하는 서비스)로 배포되어 있습니다. 실행 파일은 `index.html`이며, 제작 목적과 실제 대회와의 차이에 관한 추가 설명은 이 문서에서 안내합니다.
